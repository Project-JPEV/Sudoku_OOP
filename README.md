# Sudoku Game

A Java-based Sudoku game developed as the final project for an Object-Oriented Programming course. This project applies core OOP principles including encapsulation, inheritance, polymorphism, and modular design to create a functional and interactive Sudoku experience.

## Overview

This project was the culmination of a semester of object-oriented programming assignments focused on software design and development in Java. The objective was to create a fully playable Sudoku game while demonstrating sound programming practices and effective teamwork.

The application is organized into multiple classes responsible for game logic, board management, user interaction, and validation. This separation of responsibilities improves maintainability and demonstrates object-oriented design principles.
